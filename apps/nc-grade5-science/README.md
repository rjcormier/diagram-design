# Tar Heel Science Lab (Grade 5, NC 2023 Science Standards)

A single-file web app for teaching all 16 Grade 5 objectives in the NC DPI *Grade 5 Science 2023 Support Document* (August 2025).

Open `index.html` in any browser. It needs no build step and no server.

Each objective page includes:

- **Big idea and key ideas**, drawn from the support document's proficiency statements
- **Read and explore**: free sources (PhET, KidsHealth, NASA Climate Kids, NOAA SciJinks, NWS, NHC, NCpedia, NC Aquariums, Wonderopolis, Science News Explores, PBS LearningMedia, NatGeo Kids) and library trade books, each with a purpose question
- **Math connection** (marked MATH): the Eureka Math² Grade 5 module, the NC math standard, and a worked example
- **Lab**: interactive practice (mass/conservation scale, cooling cups graph, push test, distance–time plotting, population patterns, NC weather data, barometer forecast, sea/land breeze, particle model, sorts and model builders)
- **Science words**, **Talk like a scientist** sentence stems, and a **3-question quick check**

Stars save only in the student's own browser (`localStorage`). The **Teacher guide** view (`#teacher`) has an alignment table.
